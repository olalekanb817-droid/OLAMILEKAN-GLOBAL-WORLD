# OLAMILEKAN GLOBAL WORLD

A global business platform for technology, supermarket essentials, African products, logistics, and international trade. **One World. Your Vision.**

## Website

The responsive, static website is served from the lowercase `index.html` file in the repository root. It uses a premium black-and-gold design and includes:

- **Technology store:** smartphones, iPads and tablets, laptops, and accessories.
- **Online supermarket:** food, grocery, and household essentials enquiries.
- **African marketplace:** African products, sourcing, and supplier enquiries.
- **Logistics and international trade:** business enquiries about delivery coordination, sourcing, and cross-border trade.
- **Contact and ordering:** WhatsApp product enquiries and a contact form that opens WhatsApp with the visitor's message; email contact is also provided.
- **Responsive layout:** navigation, content, and product cards adapt to mobile screens.

Product prices and stock are confirmed directly with the business. The current site is a static catalogue and enquiry experience; checkout, payments, inventory management, and order fulfilment are not implemented.

## GitHub Pages

To publish from this repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub Pages will publish the root `index.html`; allow a few minutes for the first deployment. Check the Pages settings for the published URL and deployment status.
